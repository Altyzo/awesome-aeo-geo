# Contributing to Awesome AEO & GEO

Thanks for helping keep this list current. The AEO and GEO category moves fast — tools launch, get acquired, and shut down. Community contributions keep this list accurate.

Please note that this project is released with a [Contributor Code of Conduct](./CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.

## How to contribute

1. Fork the repo
2. Edit `README.md` only
3. Add your entry at the bottom of the relevant category
4. Open a pull request

## Entry format

```
- [Name](url) - One-line description. No marketing fluff.
```

Keep descriptions to one line. Say what the tool does, not how great it is.

## Rules

- Check the list for duplicates before submitting
- No affiliate links
- No emojis
- One entry per line
- Place new entries at the bottom of their category
- If a tool fits multiple categories, list it in the primary one only

## What we accept

- Tools, platforms, and services for AEO, GEO, or AI search visibility
- Open source repos related to AI search optimization
- Research papers, benchmarks, and datasets
- Guides and reports with verifiable data
- Standards and specifications governing AI search

## Evidence

Tools need at least one checkable signal that someone other than the maker caverify:
                                                                             - A public repository or
- A review, press mention, or listing by someone unaffiliated with the projec- A named user or custome
- For datasets and reports: downloadable data or a stated method             
"Independent" excludes the maker's own website, blog, newsletter, and launch posts. Maintainers may asline an entry that doesn'tmeet this bar. Declining is not a judgement about the product.

## What we reject

- Generic SEO tools without AEO/GEO features
- Blog posts without original data or analysis
- Tools that have been acquired and shut down
- Entries without a working URL
